# Security policy

## Supported versions

Minimix is pre-1.0. Security fixes land on `main` only.

| Version | Supported |
| ------- | --------- |
| `main`  | yes       |
| tags    | best effort while pre-release |

## Reporting a vulnerability

Email davide.magli99@gmail.com with:

- a short description of the issue
- steps to reproduce
- impact (for example unsigned driver install paths, audio sandbox escapes, or secret exposure)

Do not open a public issue for vulnerabilities until a fix is available or we agree the report can be public.

You should receive an acknowledgement within 7 days.
